# Claude Code Guide

A practical reference for configuring and using Claude Code effectively across software projects.

## What this skill covers

- Project-level guidance with `CLAUDE.md` templates.
- Prompting strategies for planning, deeper analysis, and verification.
- Debugging workflows using precise instructions and logs.
- Context management and iterative development practices.

## Usage

Use this skill when setting up Claude Code for a project, improving agent instructions, refining prompts, or troubleshooting an unproductive coding session.

Start by reviewing the project's structure and existing instructions. Adapt the examples to the repository's actual stack and commands rather than copying them blindly.

## Included files

- `SKILL.md`: The complete guide and workflow reference.

## Practical guidance

Keep instructions specific, scoped, and verifiable. Make changes in small steps, run the project's relevant checks, and confirm the result before considering work complete.
